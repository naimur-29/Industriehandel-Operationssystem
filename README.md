# Industriehandel Operationssystem

A portfolio project for a fictional German B2B wholesaler. The repository currently contains planning documents; application development starts with the customer tracer.

## Project documents

- [Product requirements](./PRD.md) define the scope and business behavior.
- [System design](./SYSTEM_DESIGN.md) records architecture choices, the proposed Git workflow, and engineering references.
- [Development checkpoints](./CHECKPOINTS.md) track small implementation tasks, human review, and future milestones.

Start with the current-work table in CHECKPOINTS.md. Each checkpoint includes preparation topics, work instructions, and acceptance checks.
